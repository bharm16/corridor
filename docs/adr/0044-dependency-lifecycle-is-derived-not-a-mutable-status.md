# Dependency lifecycle is derived, not a mutable status

A Dependency has no mutable lifecycle status. Ready, Dismissal, External Party closure, Exceptions, and the current Coordination Plan already state every supported condition; the old `identified | in_progress | committed | blocked | closed` value had no authority and could suppress or publish facts without Evidence or a Work Decision, so Corridor preserves it only as retired legacy history.
