Every actionable item of the project is listed with its own subject in project language and its own accounting; exactly one is opened at a time, and only the opened one carries decision controls, so no Proposed Delta ever grows a second control (ADR-0085). A cross-source coordination question and a shared commitment are answered child by child instead (#528): every source keeps its own row and its own value, and each gets its own answer, because one source's value may become the accepted one while another's is kept out and both halves are one act. `Review Packet` is an internal name and never appears here: an item is named by the source revision it came from, by the question two sources raised, or by the commitment it covers. Everything visible is rendered by `_primitives.html` or is ordinary prose, and no class on this page paints a state. There is no script: the selection is native checkboxes, the focused answers are native selects and text inputs, the actions are submit buttons, and the keyboard shortcuts are real `accesskey` attributes rather than hints for behaviour that is not there. The focused form sends one value per control per child, in parallel lists aligned with a hidden child identity, so every control has a static name and a child is never silently dropped by a browser that omits an empty input. #} Source changes — {{ project.name }} {{ ui.styles() }}
